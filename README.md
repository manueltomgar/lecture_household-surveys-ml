# Lectures on Using statistical learning models with household survey microdata

Author: Manuel Tomás

## About the course

This repository contains the materials for a short course on using statistical learning models with household survey microdata.

The course focuses on applied examples related to energy demand, energy poverty and environmental policy. The practical sessions are implemented in R.

## Course structure

The course is organised into four sessions:

* **Session 0: Introduction**
  Course objectives, workflow and structure of the practical sessions.

* **Session 1: Household surveys and main indicators**
  Public survey sources, household survey microdata and indicators for energy poverty and energy demand.

* **Session 2: Modelling approach and statistical learning models**
  Training, validation and comparison of models using household survey microdata.

* **Session 3: Applications and policy implications**
  Examples from the literature, policy applications and open discussion.

## Practical sessions

The course includes two hands-on sessions:

* **Hands-on 1:** Starting with Spanish household consumption microdata.
* **Hands-on 2:** Modelling energy demand and energy poverty.

Each hands-on session includes both unsolved and solved R scripts.

## Software requirements

Please install the following software before using the materials:

* **R:** https://www.r-project.org/
* **RStudio:** https://www.rstudio.com/
